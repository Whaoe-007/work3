## 硬件与引脚分配
**本工程基于 STM32F103C8T6 最小系统板，硬件接线与引脚分配如下：**
- **流水灯**：PA0 (LED1)、PA1 (LED2)、PA2 (LED3)
- **按键**：PA11 (切换方向)、PA12 (暂停/继续)
- **串口通信**：USART1 (PA9 TX, PA10 RX)
- **OLED 屏幕**：软件 I2C （PB0 SDA, PB1 SCL）

## 自定义串口反馈格式
**当收到合法的串口数据包控制指令，或按下按键改变状态时，单片机通过串口中断（`HAL_UART_Transmit_IT`）返回一次英文状态反馈，格式如下：
`STATE=<运行状态>,DIR=<方向>,STEP=<间隔毫秒>,LED=<当前LED编号>\r\n`**

**字段说明**：
- `STATE`：当前运行状态（`RUN` 表示运行，`STOP` 表示暂停）。
- `DIR`：当前流水方向（`FWD` 表示正向，`REV` 表示反向）。
- `STEP`：当前相邻 LED 的切换间隔，单位为 ms。
- `LED`：当前正在点亮的 LED 编号（1、2 或 3）。


## 代码逻辑说明
1. **按键消抖**：外部中断回调函数中使用 `HAL_GetTick()` 记录时间戳进行软件消抖（大于 200ms 才认为有效），避免了在中断中使用 `HAL_Delay()` 造成系统卡死。
2. **非阻塞流水灯**：主循环 `while(1)` 中采用 `HAL_GetTick()` 时间差判断来切换流水灯，替代了传统的 `HAL_Delay()`。这使得系统在较长的切换间隔（如 2000ms）内，依然能瞬间响应按键和串口指令。
3. **数据包接收**：使用 `HAL_UART_Receive_IT` 接收 6 字节定长数据包，定义 `__attribute__((packed))` 结构体直接映射内存，接收完成后仅在回调中置位标志，复杂的校验和解析放在主循环中执行。
4. **反馈优化**：引入了 `need_feedback` 标志位，确保串口只在按键动作或收到控制指令时反馈一次，避免了流水灯切换时造成的串口疯狂刷屏。
